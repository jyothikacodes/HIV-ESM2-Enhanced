# Scientific Methodology

This document provides a detailed scientific explanation of the machine learning and interpretability methodologies implemented in the **HIV-ESM-2** repository for predicting antiretroviral drug resistance.

---

## 1. Data Processing and Phenotypic Labeling

The repository processes genotype-phenotype resistance cohorts fetched from the Stanford HIV Drug Resistance Database (HIVDB).

### 1.1 Sequence Reconstruction
Protease and Reverse Transcriptase sequence data are represented in Stanford HIVDB format as mutation lists relative to the reference sequence **HXB2**. Full-length amino acid sequences are reconstructed by applying point mutations, insertions, and deletions to the reference protein target:
- **Protease (PR)**: 99 amino acids.
- **Reverse Transcriptase (RT)**: 240 amino acids.

### 1.2 Phenotypic Labeling Schemes
Resistance is binarized or discretized based on Fold-Change (FC) susceptibility ratios:
- **Binary Classification**:
  - **Susceptible (0)**: $\text{FC} < \text{clinical cutoff}$ (typically 2.5).
  - **Resistant (1)**: $\text{FC} \ge \text{clinical cutoff}$.
- **Ternary (3-Class) Classification**:
  - **Susceptible (0)**: $\text{FC} < 2.5$.
  - **Intermediate (1)**: $2.5 \le \text{FC} < 10.0$.
  - **Resistant (2)**: $\text{FC} \ge 10.0$.

## 2. ESM-2 Representation and Attention Pooling

### 2.1 Protein Language Model Embeddings
We utilize Meta AI's evolutionary scale protein language model **ESM-2** (`esm2_t33_650M_UR50D`, 650 million parameters).
For each reconstructed sequence of length $L$:
1. The sequence is tokenized into residue tokens.
2. A forward pass extracts representation tensors from the final layer (Layer 33) of the transformer.
3. This yields a dense feature matrix of size $L \times 1280$.

### 2.2 Learned Attention Pooling
Instead of static mean or max pooling, a custom learned attention pooling mechanism aggregates the token sequence into a fixed-size embedding vector for classification:
$$\text{pooled\_vector} = \sum_{i=1}^{L} \alpha_i \cdot \mathbf{x}_i$$
Where $\alpha_i$ are the attention weights generated by the attention network:
$$\alpha_i = \text{softmax}\left(\mathbf{v}^T \tanh(\mathbf{W} \mathbf{x}_i + \mathbf{b})\right)$$

### 2.3 Attention Modulation via Rare Mutation Weighting
To prevent the model from ignoring rare, highly descriptive drug-resistance mutations in dense continuous features, we modulate attention scores using cohort-wide amino acid mutation frequencies:
1. Compute the cohort frequency $f_i$ of each observed mutation.
2. Calculate the inverse frequency rarity weight:
   $$w_i = \frac{1}{f_i}$$
3. Apply normalization (e.g., softmax, log, or rank-based scaling) to the weights.
4. Compute rarity-weighted final attention weights:
   $$\alpha_{i, \text{final}} = \text{softmax}(\alpha_{i, \text{raw}} \cdot w_i)$$
This guides the model's pooling layer to prioritize low-frequency, highly informative resistance positions.

## 3. Explainability and Attribution

To provide high-fidelity attribution of resistance predictions back to biological residues, we implement three complementary interpretability channels.

### 3.1 Dual SHAP Consensus Explainability
We fuse structural representation behavior with clinically grounded mutation features:
1. **Attention-Aligned Residue SHAP**: Attention weights scaled by L2 embedding norms are passed to a surrogate model for residue attribution.
2. **Mutation-Level SHAP**: SHAP values are computed directly on a binary mutation indicator matrix.
3. **Consensus Fusion**: Normalized attribution values are combined via a weighted sum:
   $$\text{SHAP}_{\text{fused}} = 0.4 \cdot \text{SHAP}_{\text{residue}} + 0.6 \cdot \text{SHAP}_{\text{mutation}}$$

### 3.2 Unified Explainability Aggregator
We combine three attribution channels to form a consensus residue-wise importance profile:
- **Integrated Gradients (IG)** (50% weight): Path integral of gradients from a baseline dataset-mean embedding to the input sequence embedding.
- **Learned Attention Weights** (30% weight): The model's internal attention focus during training.
- **SHAP Proxy Projection** (20% weight): Feature SHAP values projected back to residues based on attention weights.

### 3.3 Counterfactual Causal Mutation Analysis
We validate the causal influence of mutations by running counterfactual simulations:
1. Attenuate the embedding of position $p$ in sequence $S$ (multiply by 0.1) to simulate mutation removal.
2. Measure the difference in prediction probability:
   $$\Delta P = P(\text{counterfactual}) - P(\text{original})$$
3. Rank positions and mutations by their mean absolute causal effect.

## 4. Calibration Analysis

Probability calibration ensures that output probabilities match clinical likelihood.
- **Platt Scaling**: A post-hoc logistic regression model is trained on validation predictions.
- **Isotonic Regression**: A non-parametric calibration function is fit to validation predictions.
- **Multiclass Calibration**: For ternary classification, probability calibration is performed using a One-vs-Rest (OvR) scaling strategy, scaling each class independently and normalizing predictions to sum to 1.
- **Auto-Calibration**: Evaluates multiple calibration methods and selects the best calibration model based on validation Brier score.
